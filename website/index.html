A complete geospatial pipeline for soil moisture estimation and crop suitability mapping.

Workflow

Methodology

From raw satellite data to suitability maps in a reproducible Python pipeline.

1. Data Preprocessing

Reprojection to EPSG:4326, resampling to 250 m, quality masking, and temporal averaging of 163+ satellite files.

2. TWI Computation

TWI = ln(a / tan(β)) — identifies areas where water naturally accumulates using SRTM DEM slope analysis.

3. TVDI Triangle Method

LST/NDVI feature space: dry edge (95th pctl) and wet edge (5th pctl) fitted with linear regression across 50 NDVI bins.

4. Composite SMI

SMI = 0.6 × (1 − TVDI) + 0.4 × TWI — combining thermal and topographic moisture indicators.

5. Multi-Criteria Evaluation

Weighted Linear Combination: Moisture 40%, Slope 20%, Rainfall 20%, Soil pH 20% — reclassified to FAO 1–5 suitability scale.

6. ML Classification

Three algorithms trained on 6 spectral/terrain features with Copernicus SWI as ground truth. 70/30 stratified split.

7. Accuracy Assessment

Overall Accuracy, Cohen's Kappa, confusion matrices, and cross-model comparison charts.

8. Map Generation

18 thematic maps exported as publication-ready PNG images using matplotlib.
